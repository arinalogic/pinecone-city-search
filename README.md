# Семантический поиск по фактам о городах (Pinecone + OpenAI)

Учебный проект: короткие факты о городах и странах превращаются в векторы и сохраняются в векторной базе данных Pinecone, после чего по ним можно искать **по смыслу**, а не по совпадению слов.

## Что делает проект

1. Подключается к индексу `cities` в Pinecone.
2. Превращает каждый факт из списка `city_facts` в вектор с помощью модели `text-embedding-3-small` (OpenAI через ProxyAPI).
3. Сохраняет векторы в индекс: `id` — порядковый номер факта, `metadata` — `{"text": <факт>}`.
4. Превращает поисковый запрос в вектор и находит самые похожие факты через `search_vectors` из `pine.py`.

## Параметры индекса

| Параметр | Значение |
|---|---|
| Название индекса | `cities` |
| Размерность векторов | `1536` |
| Модель эмбеддингов | `text-embedding-3-small` |

Индекс создаётся заранее в консоли Pinecone. Код проекта к нему только подключается и проверяет, что размерность равна 1536.

## Структура файлов

- `pine.py` — класс `PineconeClient`:
  - `connect_to_index(index_name, dimension)` — подключение к существующему индексу;
  - `upsert_vectors(vectors)` — запись/обновление векторов;
  - `fetch(vector_id)` — получение вектора по ID;
  - `search_vectors(query_vector, top_k, include_metadata, filter_dict)` — поиск похожих векторов;
  - `delete(vector_id)` — удаление вектора по ID;
  - `delete_all()` — удаление всех векторов в индексе.
- `test.py` — тестовые запуски:
  - проверка эмбеддинга (вывод вектора и его длины);
  - подключение к индексу `cities`;
  - загрузка фактов `city_facts` в Pinecone;
  - поиск по смыслу по списку `test_queries`.
- `requirements.txt` — зависимости: `openai`, `python-dotenv`, `pinecone`.
- `.env.example` — шаблон файла с переменными окружения.

## Запуск с нуля

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Скопируйте шаблон и впишите свои ключи:

   ```powershell
   copy .env.example .env
   ```

   ```env
   PINECONE_API_KEY=ваш_ключ_pinecone
   OPENAI_API_KEY=ваш_ключ_proxyapi
   ```

   Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.

4. Создайте в консоли Pinecone индекс `cities` с размерностью `1536`.

5. Запустите тесты:

   ```powershell
   python test.py
   ```

> Блок загрузки фактов в `test.py` сейчас закомментирован (обёрнут в `"""..."""`), чтобы не загружать данные повторно. При первом запуске уберите кавычки вокруг этого блока.

## Пример поиска

Реальные результаты `search_vectors(query_embedding, top_k=3)`:

**Запрос:** «Какая башня связана с всемирной выставкой?»

```
id=1  score=0.5240 text=Эйфелева башня в Париже была построена к Всемирной выставке 1889 года.
id=31 score=0.2524 text=Рио-де-Жанейро знаменит карнавалом и статуей Христа-Искупителя.
id=19 score=0.2517 text=Бурдж-Халифа в Дубае — самое высокое здание в мире.
```

**Запрос:** «Где находится необычный собор, который долго строят?»

```
id=6 score=0.4428 text=Собор Святого Семейства в Барселоне строится с 1882 года.
id=9 score=0.3352 text=Мачу-Пикчу в Перу был построен инками в XV веке высоко в Андах.
id=4 score=0.3162 text=Великая Китайская стена строилась и перестраивалась на протяжении многих веков.
```

**Запрос:** «Где самая длинная стена в мире?»

```
id=4  score=0.4437 text=Великая Китайская стена строилась и перестраивалась на протяжении многих веков.
id=19 score=0.4281 text=Бурдж-Халифа в Дубае — самое высокое здание в мире.
id=33 score=0.3639 text=Сахара — крупнейшая жаркая пустыня в мире.
```

`score` — степень похожести запроса и факта: чем выше, тем ближе по смыслу. Во всех трёх примерах нужный факт оказался на первом месте, хотя слова в запросе и в факте не совпадают дословно.
